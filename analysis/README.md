# Analysis Workspace

This directory contains reverse-engineering workspaces used during HCC development.

Nothing inside this directory is considered part of the final product.

Purpose:

- Analyze third-party repositories
- Study installation flow
- Identify dependencies
- Design HCC package mappings
- Validate rollback strategy

Each analyzed project receives its own subdirectory.

Example:

analysis/

    saad/

    hyde/

    ml4w/

The final implementation lives under themes/.
